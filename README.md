## G10：自己的模型、自己的存档

主界面顶部「设置 · 存档」支持Ollama本机模型、DeepSeek自备Key和自定义Chat Completions接口。默认没有Key，也不再自动使用旧代理。Key可只保留本次运行，或用个人口令加密保存。

存档支持自动保存、新建生活、另存副本、加载以及JSON导出/导入。换电脑时拷贝导出的文件即可，模型Key不随存档导出。

- 开发运行：`StartGame.cmd`，保留快速测试和体验加速。
- 发布节奏预览：`StartReleasePreview.cmd`，作物最长24小时、最远旅行7–10天，四条长途稀有保底缩短至三次成功到访。
- 独立便携包：`dist/Moss-Development/Start.cmd` 与 `dist/Moss-Release/Start.cmd`，整个文件夹复制即可玩。两个版本使用独立存档目录。
- Git：本地develop/main分支、v0.10.0标签，未配置远程；构建差异由预设控制。

## G8：把旅行的成果穿在身上

手账新增“衣橱”：山风铃解锁探险帽，湖色丝带解锁丝围巾，蜗牛旧地图解锁背包，星夜铃解锁手套。永久解锁、随时换回，不消耗宝物，不影响数值；旧收藏同样生效。目前每次穿一套，尚不支持独立部件混搭。

收藏页还可凭茶杯、金色蒲公英、萤石、蓝纹陶领取绿植、花盆、灯和地毯，再去“小屋”摆放。青石仍能放在窗台，探索成果真正留在家里。

点击已解锁明信片的缩略图或“展开明信片”，看大图、邮戳、旅行手记和祝福；可切换只看风景。画面是预生成图集，文字取保存的当地旅行手记与本地寄语。

## G7：一起慢慢长大的小屋

盆栽现用六张完整小屋画面：两款植物 × 三处位置，光照与阴影随房间一起绘制。点“收起盆栽”随时隐藏，在“小屋”换款可重新摆放。扫地去掉抠图素材，改为轻巧的原生笔触动作。

桌上小书每天首次打开更新。开启 AI 后会尝试生成当天三页故事并保存；当天再次翻页不重复请求，失败保留标注清楚的离线故事。关闭游戏不后台生成，跨日打开才更新，当前只有当天书页缓存。

右侧“写下我的喜好”打开记忆本，支持32条喜好 / 不喜好，随时修改或忘记。聊天可说“我喜欢茉莉花”“我不喜欢嘈杂的地方”；相同主题覆盖。收获、路线选择、阅读日数逐渐积累为单独的生活足迹。开启 AI 时这些内容会作为对话和每日小书的上下文。

## 开始游玩

关闭旧游戏窗口，再双击 **StartGame.cmd**。已有存档无需重置。

1. 底部「田园」选择香草、稻米、蘑菇或南瓜，点击空田播种。种子免费，作物成熟不枯萎。
2. 「厨房」按配方做饭。「远行」选择目的地与食物，确认需要的份数后出发。
3. 正常旅行从数分钟到数小时，界面不显示精确归期；需要快速试完闭环，可在「远行」底部切换体验模式。
4. 归来查看「旅途」信件、「收藏」明信片和隐藏宝物。
5. 弹窗顶部「小铺」兑换重复宝物或购物；「小屋」安放青石与家具、切换季节；「照料」煮汤或陪伴。

Esc 关闭弹窗。离线继续生长、旅行和恢复，不死亡，不设签到惩罚。体验模式只改变之后播种和出发的计时，不改变已有旅程。具体时长、配方、概率与限制见 [玩法数值](docs/G5_玩法与数值.md)。

## AI 对话

G4 已完成真实 DeepSeek 联调；本机已有加密配置。顶部「启用 AI 对话」后发送普通纸条使用 LLM。开关默认关闭，启动游戏不会自动发模型请求。旅行信仍是本地模板，明信片为 ImageGen 预生成图集，不冒充实时生成。

偏好更新由本地明确句式或记忆本表单处理，不限于雨声；复杂语义与同义词合并尚未实现。普通 AI 输出仅为文本，不发物品或改奖励。网络异常显示来源并回退本地内容。忘记影响后续生成，不回溯重写已保存书页和旅行信。密钥使用 Windows DPAPI 加密保存在忽略目录 `.local`，不写入源码；`StopAIProxy.cmd` 停止本地代理。配置文档：`docs/AI_SETUP.md`。

## 开发运行

```powershell
./run.ps1
./run.ps1 -Editor
./run.ps1 -Test
./run.ps1 -VisualQA
python -m unittest discover -s tests -p test_proxy.py -v
```

引擎在 `.tools/godot/`。其他机器先运行 `setup.ps1`，或通过 `-GodotPath` 指定 Godot 4.6.2。执行策略阻止 ps1 时可用 StartGame.cmd 或编辑器导入 project.godot。

## 存档

Godot `user://moss_save.json`，本机默认目录为 `%APPDATA%/Godot/app_userdata/苔间小屋 · Moss & Moments/`。旧 schema 1/2/3 迁移前留对应 `.v1-backup` / `.v2-backup` / `.v3-backup`，现为 schema 4。旧香草、便当、青石、记忆、信件、摆放与在途状态保留。旧旅程维持原归期和奖励，下一趟才应用新规则。

每次成功命令保存，上一份为 `.bak`，损坏文件保留 `.corrupt-时间戳`。历史信不因忘记当前雨声偏好而删除。请同一时间只开一个窗口，不在运行时手动改存档。尚无云同步、多实例写锁或服务器防改时钟。
