# G7：整景小屋、每日小书与成长记忆

日期：2026-09-11。Godot 4.6.2 / GDScript。完成本次技术与体验切片，不代表长期自主生活或原路线图全部完成。

## 本次范围

- ImageGen 以原小屋为参考生成六张完整背景：绿叶 / 小花两款 × 窗边 / 书桌 / 门边柜三处。运行时按已购款式和位置替换整张画面，无新增植物的抠图图层；收起后回到原背景。固定位置，不是自由拖动或每次操作在线绘图。
- 场景直接提供“收起盆栽”，小屋页也提供收起入口，换款能重新摆放。调整书桌按钮避免压住翻书提示。
- 扫地改为原生细线扫帚与轻尘动作，消除扫帚贴图底色；去掉窗边突兀的程序花串，季节改为少量地面叶片。沿用地毯、灯和彩旗，未将全部装饰组合烘焙。
- 每日小书：本机日期变化后首次打开更新三页内容；当天重复翻页使用缓存。AI 开关开启、对话不忙时首次打开最多尝试一次 DeepSeek，失败保留离线故事，当天不反复请求。关闭游戏不后台生成；隔天打开即可更新。AI 与离线来源明确标注。
- 通用偏好：聊天以“我喜欢……”“我不喜欢……”开头，或记忆本填写；同主题修改，逐条忘记，上限32条。旧雨声偏好迁移。朋友的话和疑问不会被当成明确偏好。
- 生活足迹：收获次数、选过的旅行路线和最近30个阅读日逐步累计，独立于玩家偏好，可单独清空。开启 AI 时已知偏好与足迹参与对话 / 今日小书；未实现任意自然语言的隐式抽取。
- schema 5 保存偏好、足迹和当天书页。生成内容只写文本，不能给予物品或执行世界操作。异步小书检查日期与 memory_epoch，记忆修改后不接纳旧上下文回复。

## 启动与体验

1. 关闭旧游戏窗口，双击工程根目录 `StartGame.cmd`。本轮本地代理已重新启动加载新协议；以后改代理代码可先运行 `StopAIProxy.cmd`。
2. 已有盆栽可直接移动 / 收起；无盆栽先在小铺购买。已买款式在“小屋”里切换。
3. 点桌上书本或“翻翻小书”。需要 AI 今日故事时先开启顶部 AI 开关；也可先读离线版，开 AI 后再打开书。
4. 右侧“写下我的喜好”或“记忆”打开记忆本，写一个主题并保存；聊天也支持明确喜好句。
5. 玩几次种植和阅读，记忆本底部会出现生活足迹。它们只是游戏行为观察，不自动等于现实偏好。

旧存档无需重置，迁移前保留 `.vN-backup`。不要用旧版本游戏覆盖已经升级的进度。测试全部使用内存或 artifacts 文件，未操作玩家存档。

## 已知限制与下一步

- 只缓存当天三页，没有跨日书架；离线故事是有限组合，不冒充实时 AI。AI 次数按本机日期计，网络失败当天保留离线版。AI 开关目前每次启动关闭。
- 日期在再次打开书时更新；已打开的书不会在午夜强制翻走。每日生成不是后台定时任务。
- 偏好匹配是明确句式与相同主题覆盖，不做同义词合并、复杂语义消歧或无限记忆。最多32条偏好；旅行信仍用原模板。忘记不回溯重写已保存文本。
- 六张绘制保持相机与家具位置，但生成式重绘有细微局部变化。只有盆栽采用整景；地毯、灯和彩旗仍是独立层。新增大量物件组合会造成素材数量增长，后续应按“窗台 / 书桌 / 门边”小区域烘焙组合与整景风格校准。
- 下一步优先做14天小书书架、持续角色经历摘要、少量朋友关系与事件后续，再增加2–3件真实可互动物件。用实际游玩检查故事重复率、自然程度和物品经济；尚未证明长期留存。
