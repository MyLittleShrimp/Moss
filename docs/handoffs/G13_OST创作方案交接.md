# G13 OST创作方案交接

## 范围

用户要求整套游戏OST的音乐风格提示词和曲目名。已完成文档设计；没有启动生成、支付服务、下载音乐或修改Godot游戏代码。宣传片音乐由用户自行完成，不再作为阻塞项。

## 文件

- `docs/G13_苔间小屋OST曲目与生成提示词.md`：专辑名称、24首正曲、3段事件短音乐、完整英文Caption、参数和场景建议、制作批次、循环和接入建议。
- `docs/STATUS.md`：当前创作方案完成，音频生成与接入未开始。
- `docs/G12_宣传片分镜与发布文案.md`、G12交接、`docs/TROUBLESHOOTING.md`：根据用户反馈结束此前配乐服务等待，保留助手未复核用户最终成片的边界。

## 使用方法

打开OST方案，把单首英文框复制到音乐生成器Music Caption，开启Instrumental，歌词留空，按表填可用参数。建议先生成01、02、05、15、18五首试听，确定统一音色后再批量补齐。用户本轮仅要求提示词，无需为完成文档额外请求生成授权。

## 检查与证据

曲目场景对照`game_content.gd`现有九条路线和G11五个途经城市：九地各有专曲，上海、迪拜、伦敦各有专曲，斯德哥尔摩与哥本哈根共用北方港湾主题。共24个正曲编号、3个短曲编号、27条完整英文提示词；表内正曲总时长3510秒，即58分30秒。未新增未实现的旅行地点。

文档以创作提案表述主题音型和游戏混音规则；没有声称文本可以保证相同旋律或无缝循环。没有运行游戏回归测试：本轮只改文档。新音频不存在，尚不能进行听感和循环验收。

## 剩余工作

用户生成选曲后可整理音频、完成统一混音和Loop剪辑，再接入音乐音量、播放列表、天气/夜间切换、明信片场景音乐与事件短音乐。本次没有提前实施这些功能。本轮无新增实际技术故障，制作注意事项写在OST方案中，不冒充已发生的问题。
