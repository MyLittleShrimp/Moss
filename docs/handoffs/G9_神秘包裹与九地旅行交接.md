# G9 神秘包裹与九地旅行交接

日期：2026-09-12。Godot 4.6.2 / GDScript。此玩法切片已完成，不代表原产品路线图全部完成。

## 交付范围

- 未发现收藏隐藏名称与原图；衣橱用灰色青蛙剪影和问号，稀有收藏用通用神秘包裹。发现后永久显示，使用或兑换重复物品不会重新隐藏。
- 首次获得宝物进入可保存的待拆包队列，点击拆包播放揭晓动画，再去衣橱试穿或领取小屋奖励。结算只发一次物品，拆包只改变展示状态，不重复发奖励。未拆物品不能穿戴、兑换或领取对应奖励。
- 新增大理·洱海、巴黎、冰岛·雷克雅未克，合计九条路线、十八种收藏、七款可解锁整套装扮及初始外观。
- 新增四种作物、四种食物，合计八种作物、七种主食与一种可选点心。新增三份小屋奖励、三张可展开的旅行明信片。
- 九地各自保存稀有掉落计数：连续未获稀有后逐步提高概率，最迟第八次成功到访获得当地稀有物品。折返不计；绕路按实际到访地计。

## 启动与体验

关闭旧游戏窗口，双击工程根目录 `StartGame.cmd`。进入手账的田园、厨房和远行。可在远行底部切换体验模式，仅影响下次播种和出发。

首次发现物品后，点击顶部包裹入口或收藏页入口拆包。衣橱可随时换回初始外观。明信片在到访后从收藏页展开。新小屋奖励先领取，再去“小屋”摆放或收起。

存档升级到 schema 7，保留旧库存、明确偏好、已发现收藏和在途旅行快照；升级前备份原版本。旧收藏直接保持已知，不要求重新拆包。旧版本没有连续未中次数，迁移时该计数从零开始。请勿用旧版程序覆盖新版存档。

## 限制与下一步

- 衣饰仍为整套外观，未知剪影是通用青蛙轮廓；不提前泄露实际衣饰形状。只有首次发现拆包，重复宝物直接入库。
- 新家居是固定位置的原生绘制小装饰，尚未为每种家居组合生成完整小屋，也不支持任意拖放。
- 明信片风景为预生成素材，旅行手记和寄语为本地内容；本阶段没有接入实时明信片生成。点心故事也是本地随机事件，不能称为实时 LLM 输出。
- 保底和经济数值已验证规则正确，尚未经过长期玩家留存测试。随后建议先实际体验普通节奏，观察食物储备、等待时长与稀有解锁速度，再调数值。
