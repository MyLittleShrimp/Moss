# G10 玩家模型、多存档与双版本交接

日期：2026-09-12。Godot 4.6.2 / GDScript。此工程切片完成，原始产品路线图尚未全部完成。

## 这次可以做什么

主界面顶部新增「设置 · 存档」，含「我的 AI 模型」和「存档与搬家」两页。

### 玩家自己的模型

- 本机 Ollama、DeepSeek 自备 Key、自定义 Chat Completions 兼容接口；玩家填完整接口地址及准确模型名称。
- 新客户端直接由 Godot 请求模型，启动游戏不再启动旧代理，不读取 `.local/ai.json` 或旧 DPAPI Key。AI 默认关闭，未配置时明确回退本地文本。
- 模型地址与名称保存在本机 `user://ai-settings.cfg`。Key 默认只留在本次运行；可用至少8位的自选口令加密到 `user://ai-key.enc`，下次启动需手动解锁。口令不保存，换电脑需重新配置。
- “测试连接”仅发送固定虚构问候。正常启用后会发送相关游戏事实、已记录偏好和生活足迹，供聊天 / 每日小书使用。
- 云端要求 HTTPS，本机回环地址允许 HTTP；禁止重定向，限制响应体和等待时间。仅接受结构正确的短文本输出，没有工具执行或库存修改权限。
- 当前兼容 `/chat/completions`，不是任意供应商任意协议；不直接支持 Anthropic 原生 Messages 或 Responses。Ollama 需要玩家自行安装、运行并下载模型，本轮未在本机安装或下载模型。

### 自动保存与便携存档

- 游戏操作沿用自动保存，正常关闭也保存；可手动「立即保存」。
- 「另存为新档」复制当前进度并切换到副本，「新建生活」开始独立进度，「加载选中存档」继续旧生活。
- 导出 JSON，复制到另一设备后导入。导入总是创建新档，不覆盖源文件或已有档；导出遇到已有目标文件会要求换名称。
- 可导入新便携封装或旧原始游戏 JSON，先验证 / 迁移，再写入。损坏 / 未知格式拒绝导入；正在等待 AI 回复时禁止切档，并额外校验回复所属 world 实例。
- 开发版首次启动将旧 `user://moss_save.json` 复制到新存档目录，旧文件原样保留。发布版默认新生活；需要旧进度时手动导入。
- 存档仍为 schema 7，新增可选显示名；便携封装版本1。在途旅程、作物截止时刻不重抽、不重置，离线时间继续算。游戏配置和 Key 不随导出迁移。
- 存档目录：`user://saves/development`、`user://saves/release`，两个版本分开。AI 配置是本机配置，可供两个版本共用，启动时仍默认关闭且 Key 未解锁。
- 此轮不提供云同步、存档删除、多实例并发编辑或跨设备冲突合并。请一次只开一个同版本窗口；聊天屏幕里的临时对话不作为永久聊天历史导出。

### 两种节奏与构建

源码默认开发节奏；发布导出预设通过 `release_pace` 特性采用独立数值，源码可用 `StartReleasePreview.cmd` 预览。节奏改变仅影响之后播种和出发，不重算旧定时器。

发布版作物：香草5分钟、稻米30分钟、玉米1小时、蘑菇2小时、胡萝卜4小时、南瓜6小时、土豆12小时、草莓24小时。最远冰岛7–10天，天气延时受该路线最大值约束；忘带东西折返会提前回来。开发版保留原速度及体验加速。

长时间远行不搭配漫长重复刷取：发布版东京、伊斯坦布尔、巴黎、冰岛最多三次成功到访获得当地稀有物；其他路线最多八次。参见 [节奏方案](../G10_发布节奏与平衡.md)。

## 启动 / 构建 / Git

- 开发源码：根目录 `StartGame.cmd`；发布节奏源码预览：`StartReleasePreview.cmd`。
- 可玩的独立便携包：`dist/Moss-Development/Start.cmd`、`dist/Moss-Release/Start.cmd`。整个文件夹一起复制，不能只发内部的 game.zip。
- 构建：PowerShell 运行 `./tools/build.ps1 -Channel Release` 或 `-Channel Development`。
- 便携包使用现有 Godot 完整二进制配合导出资源包，无需 Python、代理或本机 Godot 安装。完整二进制较大，尚未换成专用精简导出模板，未签名、无安装器。Godot 许可与第三方声明随包附带。
- 本地 Git：develop 用于开发，main 指向本轮验证过的版本，标签 v0.10.0；当前保持 develop。采用同一套代码的构建配置，避免两个分支手工维护两套业务逻辑。见 [Git工作流](../G10_GIT_WORKFLOW.md)。没有创建远程仓库或推送。
