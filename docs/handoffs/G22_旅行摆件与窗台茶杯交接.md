# G22 旅行摆件与窗台茶杯

2026-09-15。本阶段修复收藏奖励与摆放入口不一致，不增加新的旅行掉落。

## 范围与改动

- 木纹茶杯奖励由初始绿植改为独立窗台纪念品；小屋可摆放、收起，摆上时收起青石，重新摆青石时收起茶杯。
- 已领取茶杯奖励的旧档直接拥有入口，无需重领、不消耗收藏或叶币；旧奖励绿植保留。使用可选 `window_cup` 字段，不提升存档版本。
- 收藏奖励卡显示实际奖励图标：花盆、地毯、灯等不再借用解锁用的收藏物图标。尚未发现仍隐藏。
- 茶杯复用已有图集，以现有运行时白底透明材质显示，固定窗台位置；没有生成新美术。其他摆件沿用各自原有小屋位置和收起功能，本阶段没有统一自由拖拽系统。

文件：`scripts/reward_world.gd`（奖励/窗台规则/保存校验）、`scripts/life_panel.gd`（奖励卡/茶杯入口）、`scripts/main.gd`（茶杯Sprite）、`tests/test_keepsakes.gd`、`tests/capture_keepsakes.gd`、`tests/keepsakes_scene.tscn`。

## 运行

解压 `dist/Moss-Release-G22-Audio-Windows.zip` 或对应 Development 包，启动 `Start.cmd`。收藏 → 已领取茶杯 → 去小屋摆放 → 木纹茶杯。青石和茶杯共用窗台，替换不损失物品。
