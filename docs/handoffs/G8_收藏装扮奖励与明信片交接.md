# G8 收藏装扮奖励与明信片

2026-09-12，Godot 4.6.2 / GDScript。完成“探索→收藏→可见装扮”的可玩切片，非全部长期养成系统。

## 本次交付

- 新增衣橱，初始外观 + 四款 ImageGen 原创同角色装扮。找到对应宝物即永久解锁，换装不消耗收藏、不花钱、不改变旅行数值，换回初始外观自由。
- 旧存档收藏自动匹配解锁，无需重新刷宝物。首次旅行解锁会写进归来信的奖励说明；远行页显示该地装扮 / 小屋奖励目标。
- 四份小屋奖励可在收藏页领取，然后去小屋摆放。首次领取不消耗宝物，重复领取被拒绝，已买同款不补发金币、不重复加物品。青石沿用直接摆窗台。
- 六地明信片可点缩略图或“展开明信片”，显示大风景、纸边、邮戳、日期、旅行次数、收件人、保存的当地手记、祝福与落款；可切换“只看风景”，再收回相册。
- 明信片使用该地最近保留的成功旅行手记；忘带日记本折返的信不替代到访明信片。无对应旧信时显示旧相册说明与“日期未记录”，不编造历史。
- schema6 持久化当前外观与已领小屋奖励；旧版本迁移前备份，旅程、库存、记忆和每日书页沿用已有数据。

## 运行与验收

关闭旧游戏窗口，双击根目录 `StartGame.cmd`。无需重置存档，也无需开启AI就能体验本轮功能。收藏或底部入口打开手账，再选“衣橱”；找到的宝物会自动对应解锁。收藏页下方领取小屋奖励，去“小屋”选择摆放；在收藏页点明信片看大图。

## 限制与下一步

- 每次一套外观，帽子 / 围巾 / 手套 / 背包尚不能独立混搭；四款图保留角色身份但有细微绘制差异。衣饰不提高掉落或缩短旅行。
- 小屋奖励复用已有家具款式，已买过的玩家仅补领记录，无金币补偿。新增独有纪念家具可沿用此链路扩展。
- 明信片图片是既有预生成风景，画面角色不会随当前衣橱改变。手记与祝福是明确标注的本地内容，不冒充实时AI生成。各地点只有一张风景、展示最近保留的成功手记；不支持每趟独立卡片历史、导出或分享发送。
- 衣橱和收藏是当前的目标展示入口；还没有总成就页、收藏套装里程碑、稀有物品保底或长期平衡结论。
- 下一步可补两套地区收藏成就、独有房间纪念品、稀有掉落体验验证，再考虑混搭和每趟独立明信片。
