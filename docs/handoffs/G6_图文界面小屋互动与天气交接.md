# G6 · 图文界面、小屋互动与天气交接

2026-09-10。状态：本地可玩切片完成，不代表全屋编辑器或完整气候模拟完成。

## 本轮范围

- 田园、厨房、旅行、收藏、小铺、小屋、照料改为图文卡片。四作物、四食物、十二宝物都有独立插画；路线使用风景预览；选中态、库存、配方、主要按钮分层排列。
- 新小屋底图去掉不可移动的原地毯、左窗台盆栽，叠加独立可交互家具；旧背景保留。
- 盆栽可点击实物，再点「窗边 / 书桌旁 / 门口」移动。支持常青绿植和新花盆切换。
- 桌上书可点击翻开，三页本地生活短文，有翻页和阅读位置保存。
- 扫帚可点击，有约 1.8 秒动画，整洁度增加，不产叶币；离线落叶不引发疾病或奖励损失。
- 三款可用地毯：原色编织、苔绿叶纹、暖杏落日。购买即铺设，也可换回旧款。
- 晴、阴、小雨及湿度；环境明暗、窗外 / 庭院雨线随天气改变。模拟天气，不读取定位或外部天气 API。

## 运行与实际操作

关闭旧窗口，再双击 `StartGame.cmd`。旧 schema 1/2/3 自动备份成 `.v1-backup` / `.v2-backup` / `.v3-backup` 后升级 schema 4；原作物、食物、叶币、收藏、家具、偏好、来信和在途结果保留。测试未打开玩家存档。

底部田园 / 厨房 / 远行 / 收藏打开新手账。小屋目前没有盆栽时，点窗边「添一盆绿意」去小铺：原绿植 8 叶币，春日花盆 12 叶币（含可摆放盆栽）。点击实物或下方标签选择位置；再点一次或 Esc 取消。换款在「小屋」卡片操作。

地毯原色免费；叶纹 14、落日 18 叶币，购买自动铺设。点击「换张地毯」打开小屋页。点书本本体或「翻翻小书」，上一页 / 下一页 / 合上；再次打开从已读页继续。点扫帚本体或「扫扫地」，播放扫地动画。

天气每 30 分钟一个固定时段，晴约45%、阴约27%、雨约28%，同一时段重新加载保持一致。湿度按类型生成：晴42–59%、阴60–74%、雨78–92%。不影响作物成长、旅行结果或奖励。整洁度每离线/在线小时下降5，最低40；扫地+25（最高100），2秒操作间隔，无清洁收益或处罚。

## 遇到的问题

TS-014：生成图未提供真实透明 alpha，改为白底图集并在 Godot 运行时显示处理；保留模式说明。
TS-015：地毯实际输出尺寸与提示不同，按真实纹理尺寸划分图块；物品边缘轻微串格用 Atlas 区域留边解决。
TS-016：原生窗口刚缩放时 QA 过早点击导致断言失败，等待缩放完成后重测通过。

## 限制与下一步

- 盆栽是三个预设位置点击移动，不是自由拖拽；其余烘焙在背景中的家具仍不可任意移动。
- 书有三页固定本地短文，非 LLM 生成；扫地是点击触发动作，不是鼠标笔刷式擦拭。
- 湿度是氛围指标，无温度、昼夜、真实地理气候、声音或作物联动；天气暂不改旅行事件。
- 明信片沿用预生成图集；AI 对话边界沿用 G4，未增加 Agent/MCP。
- 原生白底 shader 会淡化极白高光，后续可换逐件 alpha 资产；小灯、彩旗、季节枝叶仍含程序绘制元素。地毯第四款为素材备用，没有上架。
- 下一步建议实玩验证小屋点击提示与卡片信息密度，补轻音效和青蛙看书 / 打扫回应，再决定增加可移动物件数量。
