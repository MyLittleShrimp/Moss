四作物、四食谱、六目的地、补给与耐放等级、隐藏归期随机旅行、六普通和六隐藏宝物、重复兑换、六张 AI 预生成明信片、三件可见布置、四季氛围、六类旅行结果与照料。正常节奏分钟至小时，另有明确体验模式。完整数值见 `../G5_玩法与数值.md`。

- `scripts/travel_catalog.gd`、`scripts/local_dialogue.gd`：六地名称，旅行中使用计划目的地避免泄露绕路结果。
- `assets/postcards.png` 与导入描述：1536×1024 图集，六个 512×512 AtlasTexture 区域。
- `tests/test_expansion.gd`、`run.ps1`：扩展测试与入口。
- README、STATUS、TROUBLESHOOTING、ASSET_PROVENANCE、本交接和玩法数值文档。

## 运行与存档

关闭旧窗口，双击 `StartGame.cmd`；不要同时开两个实例操作同一存档。AI 开关默认关闭，普通纸条启用后才调用模型。

schema 1/2 迁移前保留 `.v1-backup` / `.v2-backup`。保留香草、便当、青石、摆放、偏好、信件、种植时间和未完成旅程。旧旅程仍按旧归期带回青石，下一趟才走新规则。保存继续使用临时文件与 `.bak` 恢复。

```powershell
./run.ps1 -Test
./run.ps1 -VisualQA
python -m unittest discover -s tests -p test_proxy.py -v
```

## 限制与下一步

单机本地状态，无云存档、时间防作弊、并发存档锁或 Agent/MCP。便当不能混装，作物无生长阶段动画。明信片为预生成、旅行信为模板。家具为可见程序占位，季节只是氛围，无服装皮肤。没有稀有保底与长期经济 / 留存证据。

下一阶段建议先丰富朋友关系、地点故事与生活动作，替换家具水彩素材，实玩调远途等待与掉落，再开发异步明信片变体和 Agent 接口；每阶段继续独立 handoff。
