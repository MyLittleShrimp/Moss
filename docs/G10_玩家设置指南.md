# 玩家 AI 设置与存档搬家

## 配置自己的模型

在小屋顶部点击「设置 · 存档」→「我的 AI 模型」。选预设或填写完整接口地址、模型名称和自己的 Key，点「保存配置」再「测试连接」。回到小屋勾选「启用 AI 对话」。关闭 AI 后仍可使用全部离线玩法。

本机 Ollama：先安装并运行 Ollama，下载你选择的模型；在终端用 `ollama list` 查看已安装的准确名称。游戏预设地址为 `http://127.0.0.1:11434/v1/chat/completions`，Key通常留空。接口依据 [Ollama 官方兼容文档](https://docs.ollama.com/api/openai-compatibility)。游戏不负责下载或启动模型。

云端：用服务商提供的 HTTPS Chat Completions 地址，填写对应模型 ID 与你自己的 Key。地址必须包含 `/chat/completions`，不要把 Key 放进 URL。本轮不支持所有模型原生协议；原生 Messages 或 Responses 需兼容网关。

默认只在本次运行保留 Key。勾选加密保存后输入至少8位的个人解锁口令；下次启动在同一页输入口令，点击「解锁已保存 Key」。口令不会保存，忘记时重新填写服务商 Key 即可。模型地址与名称会记住，AI启用状态默认不恢复。

测试连接会调用一次所选服务，云端可能产生服务商费用；只发送虚构问候。普通聊天和小书会使用玩家提供的相关游戏上下文；模型输出只能作为文本，不发放奖励。

## 存档搬家

1. 旧设备：设置→存档与搬家→导出当前存档，选一个新的 JSON 文件名。
2. 将 JSON 拷贝到新设备，启动游戏→同一页面→导入存档为新档。
3. 继续游戏；在途旅程与作物的真实截止时刻保留。模型设置 / Key 不随存档迁移，需要另外配置。

也可导入旧 moss_save.json。损坏或不支持的文件会被拒绝，不覆盖已有进度。导入当前版本后，不要再用旧版游戏覆盖它。

另存为新档会复制当前进度并切到副本；新建生活从头开始；加载选中存档继续另一份生活。操作自动保存，另有立即保存按钮。请避免同时打开两个同版本窗口修改同一个档。当前不提供云同步。

开发和发布目录分开，通过「打开存档文件夹」可查看。旧开发进度首次运行自动复制迁入，原文件保持不变；发布版从新生活开始，需要时手动导入。

## 常见连接问题

- 连接失败 / 超时：确认本地服务已启动、端口正确；首次加载模型可能超过90秒，可先在 Ollama 中运行模型使其加载，再测试。
- HTTP 401 / 403：核对自己的 Key、权限和账户状态。
- HTTP 404：核对完整接口路径与模型名称。
- 返回格式不兼容：当前需要模型按提示输出短 JSON（utterance / emotion）。不兼容或超长响应会回退本地文本，不修改库存。
- 解锁失败：核对口令；如果更换了接口地址，请重新填写该接口自己的 Key。为防错用，加密 Key 与保存时的接口地址绑定。

本轮接口验证使用本机模拟服务，没有实际安装 Ollama 或调用玩家云端账户。
