# 苔间小屋 · Moss & Moments — G18

种一点生活，等一封远方。

一个可以种田、做饭、等小青蛙旅行归来的治愈小屋。发现旅途中的明信片与宝物，把收获变成装扮和家里的小摆设；也可以用自己的AI模型，陪它聊聊今天。

- 八种作物、自由搭配的旅行便当、九处目的地。
- 沿途来信、明信片大图、神秘收藏和旅行旅册。
- 换装、小屋布置、每日小书、晴雨变化与完整氛围音乐。
- 支持Ollama、DeepSeek和自定义兼容接口；不内置API Key，默认可离线玩。
- 自动保存、多存档和存档导入/导出。

## 选哪个包

**Moss-Release-G18-Audio-Windows.zip**：慢生活正式节奏，适合正常体验。

**Moss-Development-G18-Audio-Windows.zip**：快速测试和等比例加速，适合想提前体验或参与测试的玩家。

Windows x64，完整解压后双击Start.cmd。两个包均含音乐和音效，不需单独安装Godot。模型服务费用由玩家自行使用的服务决定；使用本机模型需要自行安装并运行Ollama。

更新前关闭旧窗口，建议先在设置中导出存档。新版本兼容旧进度；不建议将新存档降级到旧游戏。当前为开发中原型，图片为预生成素材，旅行文本为本地手记；AI用于对话和每日小书。
