### 简介

《苔间小屋 / Moss & Moments》是一款开发中的治愈旅行养成游戏。

从种下作物、制作便当开始，为小蛙准备下一次远行。九处目的地、随机旅途与途中来信，让等待也有小惊喜。旅途收藏可以解锁装扮和小屋奖励，回家还能读书、布置，慢慢积累共同的记忆。

支持玩家自备云端模型 API 或本机 Ollama。视频为独立演示档实机录制，部分生长和旅行时间已加速；目前仍在持续开发。

你最想收到哪个城市的明信片？欢迎留言。
